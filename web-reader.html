As an app

A window of its own.

WebReader can be installed. It gets an icon, and a book opens in a window of its own, with no address bar. Installed, it works offline too.

  • iPhone and iPadIn Safari: Share → Add to Home Screen.
  • MacIn Safari: File → Add to Dock. In Chrome and Edge: the install button in the address bar.
  • Windows, Linux, AndroidChrome and Edge offer to install it themselves, and WebReader’s home has an “Install as an app” link.
  • Books from other appsOn Android the installed WebReader is in the Share menu. On a computer, Chrome and Edge open a book file in it through Open With.

A new version comes by itself: WebReader’s home says “A new version is ready · Reload”.
